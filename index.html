Paste spawn

Copy a line, then press Paste spawn. The clock is the server zone. A copied aion2timers row works too. Loot and the Korean name are ignored. The clock after Spawns in is used, not the countdown.

  • Gartua 00:34
  • Immortal Gartua Spawns at 6:43 PM

A later time is today. An earlier time is tomorrow. A matching field boss keeps its interval. An unknown name is added. A clock timer is left alone.

Export

Export writes your custom timers to a JSON file. Catalog timers are not included.

Import

Import reads that file. A matching name is updated. A new name is added. Catalog timers stay as they are.
